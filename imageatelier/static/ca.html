Trust the ImageAtelier server

ImageAtelier uses HTTPS with its own private certificate authority. Install the certificate once on each device, then open the HTTPS address.

Download the certificate

This is a public root certificate for your own network only. Install it only if you trust the person who runs this server.

iPhone and iPad

  1. Open this page in Safari and tap Download the certificate. Tap Allow when asked to download a configuration profile.
  2. Open Settings. Tap Profile Downloaded near the top, then Install (enter your passcode) and Install again.
  3. Go to Settings → General → About → Certificate Trust Settings.
  4. Switch on full trust for the ImageAtelier certificate (named like mkcert …) and confirm.
  5. Open the HTTPS address of the server in Safari, then Share → Add to Home Screen.

Android

  1. Download the certificate with the button above.
  2. Open Settings → Security → Encryption & credentials → Install a certificate → CA certificate (the path varies slightly by phone).
  3. Tap Install anyway and choose the downloaded ImageAtelier-CA.crt.
  4. Open the HTTPS address in Chrome and use Install app from the menu.

macOS

  1. Download the certificate and double-click it to open Keychain Access; add it to the login keychain.
  2. Double-click the certificate, expand Trust, and set When using this certificate to Always Trust. Close the window and authenticate.

On the server Mac itself, ./setup.sh --trust-local does this for you.

Windows

  1. Download the certificate, double-click it and choose Install Certificate… → Local Machine.
  2. Choose Place all certificates in the following store → Trusted Root Certification Authorities, then finish.
  3. Restart the browser. Firefox keeps its own store: in Settings → Privacy & Security → View Certificates → Authorities → Import.
